# Inventory & Returns Management Database

## Overview
This project is a SQL database analysis project based on a fictional company that tracks customer orders, product returns, and return trends.

The goal of the project is to use SQL to organize business data and answer questions such as:
- Which states have the highest number of returns?
- Which products are returned most often?
- What return trends can help the business improve operations?

## Technologies Used
- SQL
- MySQL
- Relational Database Design
- Data Analysis

## Skills Demonstrated
- Creating and managing relational tables
- Writing SQL queries
- Using joins
- Grouping and sorting data
- Analyzing business trends
- Explaining technical findings in a business-friendly way

## Project Files
- `database_schema.sql` — table structure
- `sample_queries.sql` — SQL queries used for analysis
- `project_summary.md` — plain-English summary of findings
